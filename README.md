# Student-Hub Portal

## Project Overview

The **Student-Hub Portal** is a simple web-based project developed using **HTML** and **Internal CSS**. It provides students with easy access to important academic information such as courses, attendance, assignments, results, announcements, and personal profile.

---

## Features

* Home Page
* Login Page
* Dashboard
* Student Profile
* Courses
* Assignments
* Attendance
* Results
* Announcements
* Contact Page
* Achievements
* Time Table
* Registration

---

## Technologies Used

* HTML5
* Internal CSS

## How to Run the Project

1. Download or clone the project.
2. Open the project folder.
3. Double-click **index.html** or open it using any web browser.
4. Navigate through the portal using the menu.
