# Practical 8
1. Import `studenthub.sql` into phpMyAdmin.
2. Put the project in XAMPP `htdocs`.
3. Open `test_connection.php` in the browser.
4. Optionally import `seed_students.sql` to add 20 student records.
5. Run `php seed_accounts.php` from XAMPP to create the demo admin and student accounts.
4. Change database credentials in `db.php` if required.
