# 🎓 Student Hub Portal

## Project Overview

The **Student Hub Portal** is a responsive web application developed using **HTML5** and **CSS3**. It provides a centralized platform where students and faculty can easily access important academic information such as attendance, assignments, courses, results, timetables, and announcements. The project aims to simplify academic management through a clean, user-friendly interface. The homepage includes navigation to all major sections including Home, Login, Register, Profile, Student Dashboard, Faculty Dashboard, Attendance, Assignments, Courses, Results, Timetable, and Announcements.

## Features

* Responsive and user-friendly interface
* Home page

* User profile page
* Student dashboard
* Faculty dashboard

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open **index.html** in any modern web browser.
4. Navigate through the portal using the navigation menu.

No installation or server configuration is required.
